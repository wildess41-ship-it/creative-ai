CREATIVE AI — FONT ASSETS
==========================

Place optional custom web font files (.woff2, .woff, .ttf) here.

The system uses Google Fonts (Inter + Syne) by default, loaded
from the CDN. If you need offline support, download the fonts
and reference them in styles.css using @font-face.

Example @font-face declaration (add to styles.css):

  @font-face {
    font-family: 'Inter';
    src: url('assets/fonts/Inter-Regular.woff2') format('woff2');
    font-weight: 400;
    font-display: swap;
  }

Google Fonts download:
  https://fonts.google.com/specimen/Inter
  https://fonts.google.com/specimen/Syne
